Supported programs and capture steps

Chase Ultimate Rewards, Amex Membership Rewards (US), Capital One Miles, Bilt, United, Delta, American, Southwest, Marriott, Hyatt and Hilton.

  1. In PointUp, open Dashboard > Agents, grant consent for your program and create a token with observations:write. Save it below.
  2. Sign in to your program yourself and open its rewards balance page. Complete any sign-in or verification prompts yourself.
  3. Return here, check the captured program and points, then record. Unusual balances may need review in PointUp.

Page layouts vary. If no clear reading appears, record the balance manually in PointUp. The extension sends the detected balance and page reference, without your provider password.

PAT retries retain the same capture. A session token uses manual recording; check PointUp before retrying an uncertain manual write. Discarding a review does not undo a submission.
A pu_ token (Dashboard > Agents, scope observations:write) writes back through the consent-gated agent endpoint and needs an active consent for the program.
