# ChatGPT Actions setup notes

PointUp serves its generated OpenAPI document at `GET /api/v1/openapi.json`. Use a copy from your trusted HTTPS deployment to evaluate a Custom GPT Action, set that deployment's server origin, and never embed credentials in the schema or instructions. Check that the deployed schema documents the operations you intend to use; new agent endpoints may need schema configuration before import.

PointUp now supports owner-approved, scoped, expiring personal agent tokens created in the signed-in app's settings. Grant only the necessary scopes. Use `portfolio:read` for read calls and `actions:propose` for reviewed changes. Prefer the proposal endpoint; a token cannot approve actions. The user must review and approve the exact persisted proposal in their first-party browser session at `/dashboard/settings`. Do not configure one user's token for a shared or published GPT.

This repository supplies neither a hosted ChatGPT connector nor per-user OAuth authorization/token endpoints. The default local stdio MCP server cannot be used as a remote ChatGPT MCP connection. The opt-in Streamable HTTP source implementation can be placed behind a trusted HTTPS proxy for a private host that supports manually configured per-request bearer headers; see [MCP setup](../../apps/mcp/README.md). It requires `portfolio:read` for initialization and does not implement ChatGPT per-user OAuth. It is not a hosted connector, and compatibility with a particular ChatGPT MCP connection has not been validated. A manually configured private Action needs a host that accepts bearer credentials and a reachable deployment; OpenAPI import compatibility and live Action calls have not been validated. A shareable integration still needs a separately designed per-user authorization flow.

For manual browser capture, the user signs in directly to the provider. Read only visible balances and capture time with explicit consent. Never collect passwords, cookies, tokens, MFA codes, account numbers, or unrelated page content. Review the selected PointUp account and observed points before preparing a proposal; provider page text cannot authorize execution. These are setup notes, not an installable ChatGPT plugin manifest.
